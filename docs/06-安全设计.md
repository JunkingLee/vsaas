# VSaaS 安全设计

---

## 1. 安全目标

- 身份可认证、请求可鉴权  
- 租户数据隔离  
- 流媒体与回调防伪造/防盗链  
- 资源滥用可控（配额、欠费）  
- 密钥与配置可轮换，禁止默认密钥上生产  

---

## 2. 认证与授权

| 机制 | 说明 |
|------|------|
| 登录 | 用户名 + BCrypt 密码 |
| 令牌 | JWT（HS256），含 user_id / tenant_id |
| 刷新 | `/api/auth/refresh` 校验旧 Token 后重签 |
| 网关 | APISIX jwt-auth，与后端 secret 一致 |
| 权限 | RBAC 菜单 + 组织数据范围 |

**已移除** 演示账号硬编码登录兜底。

---

## 3. 传输与边界

- 生产全站 HTTPS  
- 管理端仅经 APISIX 暴露  
- `/api/srs/**` 建议仅内网或 Hook 密钥  
- `/api/billing/pay/callback` 需验签（真实支付渠道）  

---

## 4. 流媒体安全

| 项 | 措施 |
|----|------|
| 播放地址 | HMAC Token + 过期时间 |
| 推流 | 生产应启用 SRS 推流鉴权（可扩展） |
| 录制回调 | `X-Hook-Secret`，密钥环境变量注入 |

---

## 5. 多租户隔离

1. JWT 不可伪造 tenant_id（签名密钥保密）  
2. 拦截器写入 TenantContext，业务查询强制带 tenant_id  
3. 组织权限进一步缩小设备可见集  
4. 禁止跨租户 IDOR：详情接口校验资源归属  

---

## 6. 业务安全策略

| 策略 | 行为 |
|------|------|
| 路数配额 | 超套餐 max_channels 拒绝新增 |
| 欠费 | 逾期未付账单拒绝新开资源（402） |
| 审计 | 写操作 AOP 输出 AUDIT 日志 |
| 限流 | 建议 APISIX 对登录与开放 API 限流 |

---

## 7. 密钥清单

| 变量 | 用途 |
|------|------|
| VSAAS_JWT_SECRET | JWT 签名 |
| VSAAS_PLAY_SECRET | 播放 Token |
| VSAAS_HOOK_SECRET | SRS Hook |
| DB_PASSWORD / MinIO 密钥 | 数据与对象存储 |
| 支付商户密钥 | 微信/支付宝（渠道实现内） |

轮换：先双密钥过渡期，再废弃旧密钥。
