# VSaaS 部署运维手册

---

## 1. 环境要求

| 组件 | 最低建议 |
|------|----------|
| OS | Linux x86_64 |
| JDK | 21+ |
| Node | 18+（构建前端） |
| Maven | 3.9+ |
| CPU/内存 | 演示 4C8G；生产按路数评估 |
| 端口 | 5432, 6379, 8848, 9000, 1935, 8080, 8001-8008, 3000, 9080 |

---

## 2. 快速启动（演示）

```bash
bash scripts/start-dev.sh
mvn clean install -DskipTests
# 分别启动各模块 spring-boot:run
cd frontend && npm install && npm run dev
```

访问：http://localhost:3000  
默认用户以 seed 为准，**生产必须改密码**。

---

## 3. 生产配置

1. 复制 `docker/prod/env.production.example` → `.env`  
2. 必改：`DB_PASSWORD`、`VSAAS_JWT_SECRET`、`VSAAS_HOOK_SECRET`、`VSAAS_PLAY_SECRET`、MinIO 密钥  
3. 开启：`VSAAS_HOOK_AUTH_ENABLED=true`  
4. 中间件：`docker compose -f docker/docker-compose.prod.yml up -d`  
5. 业务：镜像构建后 K8s，参考 `k8s/`  

健康检查：`curl http://127.0.0.1:8001/actuator/health`

多副本必须有 `shedlock` 表。

---

## 4. 常见问题

| 现象 | 处理 |
|------|------|
| 编译失败 | 确认 `java -version` 为 21 |
| 登录失败 | 查 seed 用户与密码哈希 |
| 预览无画面 | streamKey 与推流一致；查 SRS |
| Hook 401 | X-Hook-Secret |
| 无法新增设备 | 配额/欠费 |

更细联调见 `CLOSED_LOOP.md`。
