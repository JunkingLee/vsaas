# VSaaS 系统架构设计

版本：1.0  
适用：私有化部署 + 公有云 SaaS 双模式  
技术栈：Java 21 / Spring Boot 3.3 / SRS / APISIX / PostgreSQL / MinIO / Vue3

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 多租户隔离 | 全链路 `tenant_id`，网关注入，业务强制过滤 |
| 大规模接入 | 设备心跳、流媒体水平扩展、异步事件 |
| 可交付生产 | 安全加固、任务分布式锁、健康检查、部署文档 |
| 双部署模式 | Docker Compose / K8s，配置外置 |

---

## 2. 总体架构

接入层 APISIX（JWT）→ 应用层 Spring Boot 微服务→ 媒体层 SRS + MinIO→ 数据层 PostgreSQL / Redis。

## 3. 微服务划分

| 服务 | 端口 | 职责 |
|------|------|------|
| vsaas-auth | 8001 | 登录、JWT |
| vsaas-device | 8002 | 设备/通道/心跳、GB28181 |
| vsaas-media | 8003 | 播放/推流地址 |
| vsaas-tenant | 8004 | 租户 |
| vsaas-record | 8005 | 录像、SRS Hook、MinIO |
| vsaas-alarm | 8006 | 告警、WebSocket |
| vsaas-billing | 8007 | 用量、出账、欠费、支付 |
| vsaas-user | 8008 | RBAC |

## 4. 技术选型

| 类别 | 选型 | 理由 |
|------|------|------|
| 语言/框架 | Java 21 + Spring Boot 3 | LTS、虚拟线程可选 |
| 网关 | APISIX | JWT 插件、高性能 |
| 流媒体 | SRS | RTMP/FLV/HLS/RTC、Hook |
| 存储 | PostgreSQL + MinIO | 业务 + 录像对象 |
