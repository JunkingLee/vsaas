# VSaaS 系统架构设计

版本：1.0  
适用：私有化部署 + 公有云 SaaS  
技术栈：Java 17 / Spring Boot 3.3 / SRS / APISIX / PostgreSQL / MinIO / Vue3

## 1. 设计目标

- 多租户隔离（tenant_id 全链路）
- 大规模设备接入与流媒体扩展
- 可交付生产（安全、任务锁、健康检查、部署文档）
- Docker Compose / K8s 双模式

## 2. 总体架构

前端 Vue3 → APISIX（JWT/限流/路由）→ 微服务集群（auth/device/media/record/alarm/billing/user/tenant）

媒体层：SRS + MinIO  
数据层：PostgreSQL + Redis  
基础设施：Nacos / RabbitMQ（可选）

## 3. 微服务端口

| 服务 | 端口 |
|------|------|
| auth | 8001 |
| device | 8002 |
| media | 8003 |
| tenant | 8004 |
| record | 8005 |
| alarm | 8006 |
| billing | 8007 |
| user | 8008 |

## 4. 关键数据流

- 预览：streamKey=`{tenantId}_{channelId}` → SRS FLV/HLS/WebRTC + 播放 Token
- 录像：SRS on_dvr → 入库 → MinIO → 回放；retain_days 清理
- 设备：心跳 → 超时离线告警 → WebSocket
- 计费：套餐/按量 → 月结 → 欠费拦截 → 支付
