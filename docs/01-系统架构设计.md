# VSaaS 系统架构设计

版本：1.0  
适用：私有化部署 + 公有云 SaaS 双模式  
技术栈：Java 17 / Spring Boot 3.3 / SRS / APISIX / PostgreSQL / MinIO / Vue3

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 多租户隔离 | 全链路 `tenant_id`，网关注入，业务强制过滤 |
| 大规模接入 | 设备心跳、流媒体水平扩展、异步事件 |
| 可交付生产 | 安全加固、任务分布式锁、健康检查、部署文档 |
| 双部署模式 | Docker Compose / K8s，配置外置 |

---

## 2. 总体架构

```
                    ┌─────────────┐
                    │  Vue3 管理端 │
                    └──────┬──────┘
                           │ HTTPS
                    ┌──────▼──────┐
                    │   APISIX    │  JWT 校验 / 限流 / 路由
                    │  API Gateway│
                    └──────┬──────┘
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
   ┌──────────┐     ┌──────────┐      ┌──────────┐
   │ 业务微服务 │ ... │ 业务微服务 │      │  媒体层   │
   │auth device│     │billing   │      │ SRS 集群  │
   │alarm user │     │record    │      │ MinIO     │
   └────┬─────┘     └────┬─────┘      └────┬─────┘
        │                │                 │
        └────────┬───────┴────────┬────────┘
                 ▼                ▼
          ┌────────────┐   ┌──────────┐
          │ PostgreSQL │   │ Redis /  │
          │            │   │ Nacos /  │
          │            │   │ RabbitMQ │
          └────────────┘   └──────────┘
```

### 2.1 分层说明

| 层级 | 组件 | 职责 |
|------|------|------|
| 接入层 | APISIX | 统一入口、JWT、限流、路由到后端服务 |
| 应用层 | Spring Boot 微服务 | 认证、设备、告警、计费、录像、用户权限 |
| 媒体层 | SRS + MinIO | 直播分发、DVR 录制、对象存储 |
| 数据层 | PostgreSQL / Redis | 业务数据、缓存、分布式锁 |
| 基础设施 | Nacos / RabbitMQ | 注册发现、领域事件（可选） |

## 3. 微服务划分

| 服务 | 端口 | 职责 |
|------|------|------|
| vsaas-auth | 8001 | 登录、JWT 签发与刷新 |
| vsaas-device | 8002 | 设备/通道/心跳、GB28181 骨架、WVP 对接 |
| vsaas-media | 8003 | 播放/推流地址、播放 Token |
| vsaas-tenant | 8004 | 租户管理 |
| vsaas-record | 8005 | 录像计划、文件、SRS Hook、MinIO |
| vsaas-alarm | 8006 | 告警上报处理、WebSocket 推送 |
| vsaas-billing | 8007 | 用量、出账、欠费、支付 |
| vsaas-user | 8008 | 用户/角色/菜单/组织 RBAC |
| vsaas-common | - | 公共模型、租户上下文、安全、事件、锁 |

模块间通过 HTTP + 共享数据库（初期）协作；关键路径可演进为 MQ 异步。

## 4. 关键数据流

### 4.1 实时预览

```
设备/推流端 → SRS(RTMP) → HTTP-FLV/HLS/WebRTC
前端 → media 获取带 token 的播放 URL → 拉流播放
```

streamKey 约定：`{tenantId}_{channelId}`

### 4.2 录像硬闭环

```
SRS DVR → on_dvr Hook → record 服务入库
         →（可选）上传 MinIO → 改写 filePath
前端按时段查询 → 预签名 URL 回放
定时任务按 retain_days 清理库 + 对象
```

### 4.3 设备在线与告警

```
设备心跳 → 更新 lastOnlineAt / status
超时任务 → 置离线 + 上报 device_offline 告警
告警事件 → WebSocket 推送到租户客户端
```

### 4.4 计费

```
用量上报 / 套餐绑定 → 月结任务出账
逾期未付 → 欠费拦截（新增设备/通道）
支付网关（mock/微信/支付宝骨架）→ 账单结清
```

## 5. 多租户模型

- JWT Claims：`user_id`、`tenant_id`
- APISIX 校验 JWT 后转发 `X-Tenant-Id` / `X-User-Id`
- `TenantInterceptor` 写入 `TenantContext`（ThreadLocal）
- 所有业务表带 `tenant_id`，查询必须过滤
- 组织级数据权限：`sys_user_org` + `device_org` 约束设备可见范围

## 6. 技术选型说明

| 类别 | 选型 | 理由 |
|------|------|------|
| 语言/框架 | Java 17 + Spring Boot 3 | 企业级生态、长期支持 |
| ORM | MyBatis-Plus | 简洁 CRUD、分页 |
| 网关 | APISIX | 高性能、原生 JWT 插件、动态路由 |
| 流媒体 | SRS | 开源、RTMP/FLV/HLS/RTC、HTTP Hook |
| 存储 | PostgreSQL + MinIO | 关系数据 + 录像对象 |
| 前端 | Vue3 + Element Plus | 管理后台效率高 |
| 任务锁 | ShedLock | 多实例定时任务不重复执行 |
| 国标 | WVP HTTP 对接 + 自研业务骨架 | 可替换真实 SIP 栈 |

## 7. 部署拓扑

### 7.1 开发 / 演示

单机 `docker compose` 拉起 Postgres、Redis、Nacos、MinIO、SRS、RabbitMQ，本机启动各 Java 服务与前端。

### 7.2 生产建议

- 业务服务：K8s Deployment，副本 ≥ 2，探针 `/actuator/health`
- APISIX：独立集群或节点
- SRS：按路数水平扩展，录制盘与对象存储分离
- PostgreSQL：主从 + 备份
- 密钥：全部环境变量 / Secret，禁止默认值上线

详见 [05-部署运维手册](./05-部署运维手册.md)。
