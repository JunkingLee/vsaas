# VSaaS 接口设计

---

## 1. 统一约定

### 1.1 响应体

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数/业务错误 |
| 401 | 未认证 |
| 402 | 欠费限制 |
| 403 | 无权限/超配额 |
| 404 | 不存在 |
| 500 | 服务器错误 |

### 1.2 认证

- 登录：`POST /api/auth/login` → 返回 JWT  
- 请求头：`Authorization: Bearer <token>`  
- 网关/服务还可识别：`X-Tenant-Id`、`X-User-Id`  
- 刷新：`POST /api/auth/refresh`  

### 1.3 内部回调

- 路径：`/api/srs/**`  
- 鉴权：Header `X-Hook-Secret`（生产必须开启）

## 3. 网关路由建议

- `/api/auth/**` → auth（登录免 JWT）  
- `/api/device/**`、`/api/gb28181/**`、`/api/wvp/**` → device  
- `/api/media/**` → media  
- `/api/record/**` → record（`/api/srs/**` 建议内网直连或独立路由+密钥）  
- `/api/alarm/**` → alarm  
- `/api/billing/**` → billing  
- `/api/user/**`、`/api/role/**`、`/api/menu/**`、`/api/org/**` → user  
- `/api/tenant/**` → tenant  

详细示例见 `docker/apisix/routes-example.yaml`。

---

## 4. 错误与幂等

- 出账：同租户同账期仅一份账单；force 接口用于测试  
- Hook：应快速返回 `{"code":0}`，避免 SRS 重试风暴  
- 支付回调：按 billId 幂等更新已支付状态
