# VSaaS 数据库设计

数据库：PostgreSQL  
字符集：UTF-8  
约定：业务表均含 `tenant_id`（平台级表除外）；时间字段用 `TIMESTAMP`。

完整脚本：`sql/01-schema-core.sql`、`sql/02-schema-billing-rbac.sql`、`sql/seed-demo.sql`  
增量：`sql/flyway/`

---

## 1. 概念模型

```
sys_tenant 1──n sys_user 1──n sys_user_role n──1 sys_role n──n sys_menu
     │              │
     │              └── n──n sys_org (sys_user_org)
     │
     ├── n device_info 1──n device_channel
     │         └── n──n sys_org (device_org)
     │
     ├── n record_plan / record_file
     ├── n alarm_record
     └── n billing_usage / billing_bill
              └── billing_tenant_package n──1 billing_package
```

---

## 2. 核心表说明

### 2.1 租户与权限

| 表 | 说明 |
|----|------|
| sys_tenant | 租户 |
| sys_user | 用户（登录名、密码哈希、状态） |
| sys_role / sys_menu | 角色与菜单 |
| sys_user_role / sys_role_menu | 关联 |
| sys_org | 组织树 |
| sys_user_org / device_org | 用户组织、设备组织（数据权限） |
| sys_audit_log | 操作审计（可扩展落库） |

### 2.2 设备

| 表 | 说明 |
|----|------|
| device_info | 设备编码、协议、IP、在线状态、最后心跳 |
| device_channel | 通道编码、名称、原始流地址、状态 |

索引建议：`(tenant_id, device_code)` 唯一；`(tenant_id, status)`。

### 2.3 录像

| 表 | 说明 |
|----|------|
| record_plan | 通道录像计划、保留天数 |
| record_file | 片段起止时间、路径、大小 |

索引：`(tenant_id, channel_id, start_time)`。

### 2.4 告警

| 表 | 说明 |
|----|------|
| alarm_record | 类型、内容、时间、处理状态 |

### 2.5 计费

| 表 | 说明 |
|----|------|
| billing_package | 套餐：价格、路数上限、存储、保留天数 |
| billing_tenant_package | 租户套餐绑定与有效期 |
| billing_usage | 用量明细（channel/storage 等） |
| billing_bill | 月账单、金额、支付状态 |

### 2.6 基础设施

| 表 | 说明 |
|----|------|
| shedlock | 分布式定时任务锁 |

---

## 3. 字段约定

| 约定 | 说明 |
|------|------|
| 主键 | BIGSERIAL / 雪花可替换 |
| 状态 | 0 无效/离线/未支付，1 有效/在线/已支付（表内注释为准） |
| 删除 | 当前物理删除为主，重要数据可改为逻辑删除 |
| 密码 | BCrypt 存储，禁止明文 |
