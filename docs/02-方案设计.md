# VSaaS 方案设计

---

## 1. 业务背景与范围

面向安防 / 园区 / 连锁等场景，提供**视频监控云服务（VSaaS）**：

- 设备接入与通道管理  
- 实时预览与录像回放  
- 告警中心  
- 多租户 SaaS 与私有化  
- 计量计费与欠费控制  
- 国标 GB28181（对接 WVP 或自研 SIP）

**本期范围**：管理端 + 核心后端微服务 + SRS 流媒体 + 计费与安全基线。  
**不在本期**：完整 SIP 协议栈实现、客户端 App、AI 算法仓。

---

## 2. 角色与权限

| 角色 | 能力 |
|------|------|
| 平台超管 | 租户开通、套餐、全局运维（可扩展） |
| 租户管理员 | 本租户用户/角色/组织/设备/计费 |
| 操作员 | 预览、回放、处理告警（按菜单与组织授权） |

权限模型：RBAC（用户-角色-菜单）+ 组织数据范围（用户-组织-设备）。

---

## 3. 核心业务方案

### 3.1 设备与通道

- 支持协议标识：RTSP / ONVIF / GB28181  
- 设备心跳更新在线状态；超时自动离线并告警  
- 通道绑定设备，预览以通道为粒度  
- 配额：按租户套餐 `max_channels` 限制新增  

### 3.2 实时预览

- 统一 streamKey：`{tenantId}_{channelId}`  
- media 服务生成 FLV / HLS / WebRTC 地址  
- 播放 URL 附加 HMAC Token，防盗链  
- 前端 flv.js 拉流；可扩展 WebRTC  

### 3.3 录像与回放

- SRS DVR 分段录制，Hook `on_dvr` 自动入库  
- 可选上传 MinIO，回放走预签名 URL  
- 录像计划定义保留天数，定时清理索引与对象  

### 3.4 告警

- 业务上报 + 系统自动（离线、断流）  
- 列表查询、处理状态  
- WebSocket 按租户实时推送  

### 3.5 计费

| 模式 | 规则 |
|------|------|
| 套餐 | 读取 `billing_tenant_package` 有效绑定价格 |
| 按量 | channel × 单价 + storage × 单价（可配置） |
| 出账 | 月初自动出上月账单；失败小时级补偿 |
| 欠费 | 逾期未付（默认 15 天）禁止新开设备/通道 |
| 支付 | PaymentGateway 抽象；mock / 微信 / 支付宝骨架 |

### 3.6 国标 GB28181

- **业务骨架**：注册 / 保活 / 目录 / Invite / Bye  
- **生产推荐**：部署 WVP-GB28181，本系统通过 `/api/wvp/**` 代理设备列表与点播  
- 点播得到流后仍进入 SRS，与普通通道预览模型统一

## 4. 多租户与 SaaS 方案

```
开通租户 → 绑定套餐 → 创建管理员 → 录入设备/通道
         → 用量与路数受套餐约束 → 月结账单 → 支付
```

隔离维度：

1. 认证：JWT 携带 tenant_id  
2. 网关：Header 传递  
3. 数据：表字段 + 查询过滤  
4. 资源：配额与欠费策略  

私有化可将单租户固定为 1，关闭租户开通流程。

## 5. 流媒体方案

| 能力 | 实现 |
|------|------|
| 接入 | RTMP 推流 / 国标转推 |
| 分发 | HTTP-FLV、HLS、WebRTC（SRS） |
| 录制 | SRS DVR + HTTP Hook |
| 存储 | 本地过渡 + MinIO 对象存储 |
| 鉴权 | 播放 Token；Hook 共享密钥 |

扩展：SRS 集群、边缘节点、按租户独立 app。

---

## 6. 集成方案

| 外部系统 | 方式 |
|----------|------|
| APISIX | JWT 插件 + 上游服务发现 |
| WVP | REST 代理（设备/通道/点播） |
| 微信/支付宝 | PaymentGateway 实现类 |
| 监控 | Actuator health + 后续 Prometheus |

---

## 7. 方案对比与取舍

| 决策点 | 选择 | 说明 |
|--------|------|------|
| 网关 | APISIX 而非 Spring Cloud Gateway | 性能与插件生态，JWT 可下沉 |
| 流媒体 | SRS 而非自研 | 成熟稳定，Hook 易做闭环 |
| 国标 | WVP 对接优先 | 降低 SIP 研发成本 |
| 库表 | 共享库 + tenant_id | 中小规模简单；超大规模可拆库 |
| 消息 | 本地 Event 默认，Rabbit 可选 | 降低演示门槛，生产可打开 |

## 9. 风险与对策

| 风险 | 对策 |
|------|------|
| Hook 被伪造 | 生产开启 X-Hook-Secret，仅内网 |
| 播放地址泄露 | Token 短有效期 + 网关校验 |
| 定时任务重复 | ShedLock + shedlock 表 |
| 录像磁盘占满 | 保留天数策略 + MinIO 生命周期 |
| 默认密钥上线 | 部署清单强制检查环境变量 |
